# The OpenCaptions name and icon

The code is open source under [AGPL-3.0-only](LICENSE), and you are welcome to fork it, change it and
publish your version. The name and the icon are not part of that licence. They tell people which app
comes from this project, and the people who pay for the App Store version rely on it.

**Fine without asking:**

- Saying your project is based on, a fork of, or compatible with OpenCaptions.
- Writing about OpenCaptions, reviewing it or teaching it, using the name and the icon to refer to it.
- Running an unmodified copy for yourself or your team, under its own name.

**Please do not:**

- Publish a modified version, or any app in an app store, under the name OpenCaptions or with its icon.
- Use the name or the icon in a way that suggests this project made, approved or supports something
  it did not.

A fork needs its own name and its own icon. Questions: [open an issue](https://github.com/leogaudin/opencaptions/issues).
